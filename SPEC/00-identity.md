# Mason — Identity (SPEC/00)

Architect-owned. Implementers do not edit this file.

## Product

**Mason** is an additive action layer for World of Warcraft Retail 12.x (Midnight).

A player starts with zero on-screen pieces. Each piece is a bind (spell, item, or macro) that may optionally appear as a placed widget on the HUD. There are no bars, rows, columns, or empty slots.

Tagline: Place your abilities.

Principle: Additive interaction layer. No bars to subtract from.

## Frozen decisions

1. Retail Midnight (12.x) only.
2. Named secure executor + `SetOverrideBindingClick`.
3. Steal the key and toast what was unbound.
4. Binds (kit) per specialization; layout per character.
5. Libs when needed: Ace3, AceDB, AceConfig, LibDeflate, vendored LibActionButton, optional Masque. Phase 1 may use AceAddon + AceDB only.
6. Canvas-first + one config window (not Phase 1).
7. Coexist with Blizzard default bars. Do not hide them.
8. Follow CVar `ActionButtonUseKeyDown`.
9. Drop types (later phases): spell + item + macro.
10. Flyouts (later): 12 precreated children, one flyout open.
11. Visibility language (later): macro-condition string + named presets.
12. Name Mason, slash `/mason`.
13. Import schema version; refuse newer major; migrate older (not Phase 1).
14. No Blizzard Edit Mode in v1. Own lock/unlock canvas later. Isolate from Ellesmere UI (no reparent of Blizzard frames).

## Non-goals (all phases unless a later spec explicitly lifts one)

- No Blizzard action-slot writes (`PickupAction` / `PlaceAction` / `C_ActionBar.PutActionInSlot` to build the kit).
- No Cooldown Manager integration.
- No Edit Mode registration.
- No hiding default action bars in v1.
- No free rotation of buttons.
- No Classic / Era / Mists TOC.
- No aura/resource conditions as *secure* hide (paint only, later).
- Do not start Phase N+1 in the same implementer session as Phase N.

## Learn / talent rules (data policy; UI is a later phase)

When a spell becomes usable:

- In this spec kit AND layout has a saved view → auto-place, no prompt.
- In this spec kit AND crate-only → enable executor/key only, no prompt.
- Not in kit → prompt later (Bind / Place / Ignore / Later). Never silent-place.
- Unlearned → hide view, keep piece record and layout.

Phase 1 does not implement learn detection. It must not write piece IDs in a way that blocks this.
